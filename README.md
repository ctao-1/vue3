<h1>项目简介</h1>
基于Vue3架构加载Cesium三维引擎实现地理信息可视化,使用Express.js作为后端框架，数据库是postgreSQL，CORS中间件实现数据传输，同时使用axios和jQuery两种数据请求方式
<hr>
<h2>1.vue-cesium1前端</h2>
<br>切换执行目录
<small>  cd vue-cesium1</small>
<br>启动项目
<small>  npm run dev</small>
<h2>2.czlu_backend后端node.js</h2>
切换目录
<small>  cd czlu_backend</small>
<br>启动后端
<small>  node index.js</small>
<hr>
<p>前端采用 HTML5、CSS3 和 JavaScript 编程语言，框架选用CesiumJS 以支持三维地图的渲染，前端界面设计则在 Vue.js框架中实现，以确保组件化开发和维护的便利性</p>
